# Decode patterns — Hermeneia

Disclosed framework. Read when decoding a JD. English only. No third-party branding. No bilingual packs.

Use for: (1) translating marketing JD lines into hiring-manager needs; (2) reading hidden signals from wording.

---

## 1. Marketing line → real need

| JD says | Usually means |
|---|---|
| "strong experience with X" | Did X 1–2 times and can explain it — not necessarily years as an expert |
| "deep expertise in X" | 5+ years in X; expect reference checks |
| "passion for X" | Soft interest signal; still need a real story |
| "working knowledge of X" | Can discuss; not required to have shipped X |
| "exposure to X" | Nice-to-have; optional |
| "you've shipped …" with concrete artifacts | Portfolio / case evidence expected |
| "thrive in fast-paced environment" | High change rate; possible long hours |
| "comfortable with ambiguity" | Little written spec; you define the problem |
| "wear many hats" | Thin staffing; fuzzy boundaries |
| "self-starter / self-directed" | Low micromanagement; you push work |
| "collaborate cross-functionally" | High coordination / politics cost |
| "data-driven" | Decisions need evidence, not instinct alone |
| "user-obsessed / customer-obsessed" | User needs beat internal stakeholders |
| "high bar / craft / pixel-perfect" | Strict review; many iterations |
| "scale" / "scaled X to Y" | Large product or traffic experience |
| "0 to 1" | No playbook; exploration |
| "1 to N" / "scaling stage" | PMF exists; grow and harden |
| "transform" / "modernize" | Legacy / rebuild work |
| "thought leadership" | External writing / speaking expected |
| "mentor / coach others" | Senior+; has led people |
| "player-coach" | IC work plus people lead (~1.5× load) |

## 2. Hidden signal dictionary

### Drive vs execute

| Wording | Signal |
|---|---|
| ambiguity / unstructured / no playbook / undefined | Self-directed problem-finder |
| ownership / accountable / drive / end-to-end | Owns the whole outcome |
| wear many hats | Fuzzy role edges |
| structured / process / framework / established | Process executor |

### Collaboration density

| Wording | Signal |
|---|---|
| influence / align / partner / persuade | High politics / persuasion |
| stakeholder management / cross-functional | Complex up/down/side reporting |
| autonomous / independent work | Mostly solo IC |
| highly collaborative team | Meeting-heavy / consensus |

### Pace and pressure

| Wording | Signal |
|---|---|
| fast-paced / move quickly / ship fast / scrappy | Fast pace; early stage possible |
| iterate quickly / fail fast | Experiment culture |
| high bar / high standards / craft / quality | Strict review culture |
| thoughtful / deliberate / measured | Slower, decision-quality first |

### Culture

| Wording | Signal |
|---|---|
| mission-driven / impact | Mission fit will be probed |
| inclusive / diverse / belonging | DEI culture weight |
| ego-less / humble | Soft-skill screen heavy |
| bold / opinionated / strong POV | Push views or lose |
| customer-obsessed / user first | User beats internal politics |
| metrics-driven / data-informed | Need evidence for decisions |

### Stage

| Wording | Signal |
|---|---|
| build the team / founding member / first X hire | 0–1; set everything up |
| scale / grow / expand the team | 1–N; copy a playbook |
| mature / established / optimize | Maintain and optimize |
| transform / rebuild / modernize | Rebuild load |

### Level hints

| JD hint | Likely level |
|---|---|
| "manage other …" / "team of N" | Manager / Lead+ |
| "set vision / strategy" | Principal / Director |
| "execute against roadmap" | IC mid–senior |
| "ship features" without vision | IC mid |
| "thought partner to CEO/CPO" | Principal / Lead |
| "first X hire" | IC title, Lead-shaped work |

## 3. Red flags (decode carefully)

| JD says | Watch for |
|---|---|
| "wear many hats" + five job shapes | One hire doing three jobs |
| "fast-paced" + denial of work-life trade-offs | Chronic overtime |
| "we're like a family" | Boundary / overtime culture |
| "rockstar / ninja / 10x" | Immature hiring language |
| Huge salary band (e.g. $80k–$250k) | Level fog / lowball risk |
| 10+ must-haves | Unclear HM; noisy screening |
| Role open 6+ months | Internal disagreement on bar/level/pay |
| Huge X+Y+Z span in one hire | Cost-saving mashup role |

---

## 4. Decode output shape (per layer)

For each of the five layers, write **3–5 English bullets**. Label evidence (`from JD: "…"`, `inferred from: …`). Never invent company facts you did not see.

| Layer | Focus |
|---|---|
| Requirements | HM translation of key lines (what they really want / do not need) |
| Must-haves | Verifiable reject-if-missing items + why must |
| Nice-to-haves | Plus items; missing ≠ auto-reject |
| Hidden signals | Culture / drive / pace inferences + resume/interview angle |
| Level / team / stage | Title vs real level, size, stage, reporting, hiring motive — mark “JD silent” when unknown |
