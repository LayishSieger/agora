# ADR 0008 — Installed blueprints live at `/workspace/bots/<name>/` on the Grok computer

The GitHub repo already authors `bots/<name>/`. After fetch, Agora writes that tree to the **installer computer** at `/workspace/bots/<name>/` with a `RELEASE` file — not under `/workspace/agora/` (career data) and not versioned subfolders (old snapshots stay on GitHub Releases). If a **child** bot of that name already exists, do not CreateAgent a duplicate; if `RELEASE` is missing or older than latest, ask before refreshing files/description/skills. **Agora** on disk is not a child: self-materialize atomically replaces `/workspace/bots/agora/` with no ask and never CreateAgents Agora (ADR 0015).
