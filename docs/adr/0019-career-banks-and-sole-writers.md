# ADR 0019 — Career banks and sole-writers under /workspace/agora/

Durable career outputs stay under `/workspace/agora/` with one sole-writer per path: Mneme (masters + story-bank), Euodia (journey.md), Zetesis (jobs/), Hermeneia (jd-bank/), Kairos (applications resume md + one simple HTML loader), Peitho (offer-bank/, deal-bank/). English only. Minimal markdown first. No third-party brand footers. DMs carry path/id pointers; receivers read the SoT files.
