# ADR 0006 — Fleet children are created in-app, not as independent templates

We considered installing Euodia/Mneme/later stages via their own `https://x.ai/bot/…` Add links. Layish chose GitHub blueprints + CreateAgent instead: those bots are stages in one career flow, not standalone products. The only published template in v1 is thin Agora. Independent child templates stay deferred (ADR 0004).
